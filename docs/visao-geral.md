# PIE — Visão Geral

PIE é uma plataforma de **inteligência de dados empresariais brasileira** para prospecting B2B.

## Por que existe

Permite que equipes de vendas e inteligência comercial segmentem e qualifiquem empresas a partir dos dados abertos da Receita Federal (71M CNPJs), enriquecendo as listas com presença digital (sites, redes sociais, telefones) e gerenciando o pipeline de vendas resultante.

## Funcionalidades principais

- Criar **segmentos** (filtros multi-critério: CNAE, UF, situação, porte, capital, município, bairro)
- **Sugestão de filtros** por linguagem natural via Claude AI (Sonnet)
- **Enriquecer** listas com websites, Instagram, Facebook, LinkedIn, WhatsApp, Google Places, ReclameAqui
- Classificar e validar **telefones** (celular/fixo/inválido/sem telefone)
- Gerenciar **leads** (novo → qualificado → contato → convertido/descartado)
- **Pipeline de oportunidades** de vendas (stages: novo → sell_out)
- **Análise estatística** da base (por UF, CNAE, município, situação) com gráficos

## Fluxo principal

```
Segmento (filtros) → Enriquecimento → Leads → Oportunidades
```
